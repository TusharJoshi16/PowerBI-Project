# Global Superstore Dashboard

Crime Statistics Across India Dashboard | Power BI

- Designed an interactive Power BI dashboard to analyze multi-year crime statistics across Indian states and regions.
- Visualized trends and patterns related to violent crime, property crime, crimes against women, police accountability, and judicial processes.
- Created interactive KPIs, geographical visualizations, and time-based analysis to identify changes in crime patterns across regions.
- Applied data transformation, DAX, and visualization techniques to present complex crime data in a clear and analytical format for research and public-sector use cases.
