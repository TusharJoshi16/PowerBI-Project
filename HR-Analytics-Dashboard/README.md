# HR Analytics Dashboard

HR Analytics Dashboard | Power BI

- Developed an interactive HR analytics dashboard to analyze workforce demographics, employee hiring, separations, performance, and workforce trends.
- Used data visualization and analytical techniques to identify patterns supporting recruitment, retention, and workforce planning.
- Created dynamic reports with KPIs, trend analysis, and regional/time-based comparisons to provide actionable workforce insights.
- Applied Power Query, DAX, data modeling, and interactive Power BI visualizations to transform raw HR data into meaningful business insights.
